Analisi DE · API e consenso BU

L’analisi funziona interamente nell’estensione, nella sola BU configurata. Inserisci qui una volta i dati dell’Installed Package Salesforce Server-to-Server con lettura Data Extensions e Automations. I permessi effettivi sono quelli assegnati al pacchetto dall’amministratore.

Collegamento Salesforce della BU Le credenziali sono conservate nello storage locale protetto dell’estensione in questo profilo browser, senza cifratura aggiuntiva. Non vengono inserite nello ZIP né comunicate alla pagina Salesforce. Non inviarle in chat.

I token vengono rinnovati automaticamente. Alla scadenza del consenso o al riavvio del browser verrà richiesta la sola approvazione BU; non devi reinserire le credenziali salvate. Puoi ripristinare i consensi dalle impostazioni dell’estensione.

Dopo il salvataggio apri una DE in Contact Builder → Data Extensions e premi Dove viene usata. Non servono Node, Git o programmi locali. Guida alla configurazione
